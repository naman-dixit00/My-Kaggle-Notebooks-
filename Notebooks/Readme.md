## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/naman-dixit00/My-Kaggle-Notebooks-.git
cd My-Kaggle-Notebooks-/Notebooks

```

### 2. Environment Setup

It is highly recommended to run these in an isolated Python environment (like Conda or venv). Most of these notebooks utilize standard data science libraries (numpy, pandas, scikit-learn, xgboost, torch/tensorflow).

### 3. Running Locally

Launch Jupyter Notebook or Jupyter Lab to open the `.ipynb` files:

```bash
jupyter notebook

```
